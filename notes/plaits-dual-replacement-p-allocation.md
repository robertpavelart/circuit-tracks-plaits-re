2026-10-15. Target: MIDI1 and MIDI2 each have an independent monophonic Plaits instance, executing one shared code copy on core 0. Stock Synth1/Synth2 and unrelated B1.3 features remain. Neither old MIDI oscillator is a regression control.

ARM execution and full retained-workload replay remain unperformed. Keeping those controls gives a conservative assembled candidate of 1,094 words.

PROVEN means directly established by source bytes, assembly or the stated offline replay. STRONG INFERENCE means source-supported architecture or a contract not executed end to end. UNKNOWN means the required evidence is missing. These labels never imply physical memory ownership or hardware validation.

Only CIRCUIT gained study scripts, DSP-only word streams, replay inputs/results and this report. No firmware/application image or flash package was generated. No reference file was changed or added. No Plaits engine was ported.

## E — One shared code copy, two instances

**PROVEN reference architecture:** `vcf21_dsp.py:code/control/channel` already invokes shared routines with track-relative state records, stride 48. Replacing both engines does not itself require code duplication. **STRONG INFERENCE for the unported Plaits implementation:** make the renderer take a per-instance state pointer and execute sequentially for MIDI1 and MIDI2. A selected track must never mutate the other track's record. Non-reentrant temporary workspace can be shared only after proving callers/interrupts cannot overlap; persistent state cannot.

Pinned original Plaits evidence: Voice member state (local-only reference: `plaits/upstream/plaits/dsp/voice.h:210`; not distributed), Voice::Init/allocator (local-only reference: `plaits/upstream/plaits/dsp/voice.cc:37`; not distributed), Voice::Render (local-only reference: `plaits/upstream/plaits/dsp/voice.cc:90`; not distributed), [full source/state audit](<plaits-full-b13-feasibility.md>). Source revision `08460a69a7e1f7a81c5a2abcc7189c9a6b7208d4`, stmlib `e3bd7c9cc00e4364166f9905c0509b6ffd0535ec`, all 183 selected files hash-verified.

| Resource | Sharing rule |
|---|---|
| Instructions, immutable LUTs, read-only wavetable/resource banks | One copy; identical addressing and representation must be supported. No claim that the full original engine set fits 1,196 words. |
| Phase, pitch smoothing, engine selector/trigger histories | Independent per instance. |
| Decay/LPG envelope, limiter/postprocessor, engine internal filter/interpolation histories | Independent per instance. |
| Mutable delay/string/modal/resonator buffers | Independent active-instance allocation; allocator backing cannot alias between simultaneous voices. |
| RNG | Explicit per-instance stream if independent deterministic voices are required. Original/global RNG behavior must be examined rather than assumed instance-local. Multiword RNG representation requires enough cells. |
| Output/scratch buffers | Can be sequentially reused only with lifetime/caller proof; retain output until consumed. Mutable decoded/user-resource caches are not automatically immutable shared tables. |

No two-instance state capacity or DSP timing feasibility is claimed by this program allocation study.

Collect every ACT/DFLAGS message/state seen at the DSP boundary, including idle/retrigger, FX-sequencer, granular, line, step-drummer and restored patches. Include bootstrap count/entry relocation and core-1 scheduling effects. Compare all retained outputs/state; intentionally omit old MIDI synthesis equality. Until that evidence exists, another Plaits port would spend an unqualified allocation.
