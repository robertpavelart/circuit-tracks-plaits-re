## Alternative deliberate X-object takeover

Exact candidate X:[57B,582), first7 of42 active slot0 generator fields.
It is not unused and not safely persistent under the retained original prefix.
Other slot records start at stride4A, but foreign writes remain independent.

To permanently cede these words:

1. Gate selected preparation387 before any read/write of those fields. Preserve
   needed post-prefix46E..4D3 behavior only after proving it independent.
2. Replace selected77F lane paths in BOTH request and completion. Skipping
   completion only permits request writers to corrupt the new representation;
   skipping requests blindly breaks publication/result obligations.
3. Replace selected lookup/completion/auxiliary provenance with an explicit new
   contract, including2C02,2C24 andguard2C66. Do not clone an arbitrary guard or
   substitute zeros without downstream proof.
4. Prevent reset/host/table/foreign/DMA X stores to the seven words while owned.
   P204B must avoid the pre-store destination read/MAC as well as final store.
5. Leave remaining slots, bank1, event/allocator/post contexts and mixed output
   original, with no hidden shared-state aliases.

This disables the selected original generator and replaces it with Plaits intent;
it is not the narrow late mono overwrite anymore. The first seven fields cannot
be partly reused while old lanes interpret them. Required producers/readers are
listed in the exported selected-path CSVs, but complete takeover/auxiliary ABI
is **UNRESOLVED**. No implementation/cycle saving is claimed.
