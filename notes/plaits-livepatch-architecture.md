## A–C. Boundary and required original work

**VERIFIED:** request and completion are distinct. Descriptor traversal198D
sets X2F30 bit23; 77F publishes pending work, queue pointers and ICC endpoints.
Request returns at9A4. Completion19BF clears bit23, consumes bitmap slots and
calls77F at19E6 to consume fetched results. Retain both passes, polling and all
queue/phase bookkeeping; do not bypass them by filling a mono buffer.

Original preparation387 builds three14-word generator records/kernel data;
46E..4D3 prepares ramps/post/gain. The completion-only9A5..9B8 stage generates
six32-sample coefficient ramps, advances current coefficients, sets Y7=Q+30
and R4=S+0C. Q=57B+4A*i; S=59F+28*i. At slot0 both numeric cursors are5AB,
but in different memory spaces. Here0C is12 decimal words.

**Chosen conditional interception: P9B9. Chosen continuation: unchanged P9D9.**
This is after required coefficient/state preparation and outside the just-ended
local generator loops. It is not permission to skip the remaining combiner.

The original32-P-word region[9B9,9D9) initializes pointers and runs DO32 ending
at9D8. It writes three related streams:

|Producer|Destination|Reason to retain|
|---|---|---|
|9D8|X[2C46,2C66),32 mono words|baseline mono before overwrite|
|9CA, R3 advanced9D4|X[2C02,2C22),32 words|routing1 post side stream|
|9CD|X[2C24,2C44),32 words|routing2 post side stream|

**VERIFIED:** unconditional combiner removal would remove side-stream production
used by some post modes. Therefore this first design retains the **entire**
combiner. There is no proven smaller all-mode suffix; request/lane work also
remains intact. Generator work saved in this design is **zero**.

Conditional flow:

```text
original request pass and completion lanes
→ original six coefficient ramps and Y7/R4 preparation
→ P9B9 two-word trampoline
    non-selected: restore dispatcher SR; replay displaced MOVE1400,R0
                  → original P9BB..9D8 → original P9D9
    selected:     restore dispatcher SR; execute complete relocated combiner
                  → save original combiner liveout
                  → VariableSaw overwrites mono32 only
                  → restore liveout → JMP original P9D9
→ original R0 reload +three NOPs → original post/filter/gain/mixer
```

The retained combiner clone changes only its DO end address for placement.
No clone binary or patch bytes were emitted. The entry replaces a complete
two-word instruction; the fallback replays it once. A hook at9D9 would complicate
return to that same address or require replacing its reload/NOP continuation.
A branch inserted at9D7/9D8 is near the DO endpoint and conflicts with documented
loop restrictions. Neither is selected. Original9D9 remains intact.

## F. Guard and CCR

**VERIFIED selected lookup path:** 7F1/7F2 write two phase words per sample over
X[2C46,2C86). At iteration16,7F1 writes the guard location2C66 with the pre-add
A1 phase. It depends on the most recent applicable lane/repeat, start phase,
prepared increment and stock arithmetic. The final combiner overwrites only the
first32 words, leaving2C66 untouched. Other generator classes can leave an older
natural word there; no universal guard value follows.

Keeping original request/completion lanes preserves this provenance. The combiner
suffix alone does **not** establish the guard. Plaits must write exactly
X[2C46,2C66), never2C66. No zero, duplicate-last, or snapshot-derived sentinel.
Post BE6/BE7 can read it and update CCR; C9F later overwrites it on the selected
filter path. Preserve original combiner liveout SR before renderer work and restore
it before9D9. Later post arithmetic legitimately responds to changed audio.

## G–J. Preservation, selection and controls

**BOUNDED-PROOF conservative register union:**26 saved24-bit words:
R1..R7, N0..N7, raw A2/A1/A0/B2/B1/B0, X0/X1/Y0/Y1 and SR. R0 is intentionally
clobbered; original9D9 reloads it from untouched Y7. M0..M7 and OMR are not changed.
Require qualified linear M0 for direct output and compatible arithmetic modes;
do not transplant harness SR300, OMR0, M=FFFFFF or SP/SC0 into stock execution.

Balanced renderer DO plus native ratio JSR restores inherited loop/stack context,
conditionally with adequate headroom. The renderer adds up to three stack entries
(DO double push plus helper call). A JMP entry/exit adds no new return frame.
Do not repair stack corruption by blindly restoring SP/SC. Full wrapper legality,
raw transfers, mode eligibility, interrupt interaction and pipeline timing remain
**UNRESOLVED**. The26-word set is bounded; an implemented preservation certificate
is not established.

**Conditional inexpensive discriminator:** normal completion at9B9, XCC=0 and
R4=5AB identify numeric bank0/slot0 within the verified descriptor layout.
No unresolved UI/project association is needed. Product name “Synth1” remains a
**HYPOTHESIS** for bank0, not independently proved UI numbering. Bank1 and every
other slot take the original fallback. This targets a predetermined allocator
slot, not every note or a new mono allocator: a note allocated elsewhere remains
stock. Additional arithmetic/block/memory/stack eligibility must be qualified
or fall back.

Dispatcher A/B scratch is locally dead:9C8 defines A and9C9 defines B before their
first combiner uses. Save entry SR in B1 while comparisons use A; restore it before
either original continuation. Do not let comparisons leak flags into fallback.
Proposed template:12 selected-prefix P words plus4 fallback words, with a two-word
hook replacing the existing two words. **CALCULATED**, unassembled: selected
dispatcher24 cycles; wrong-slot overhead18, wrong-bank overhead26, under stated
family/private-memory rules including a two-cycle status-read allowance. Extra
mode/initialization checks are excluded; these are not measured exact patch costs.

Branch/trampoline plus direct JMP is preferred. JSR/RTS entry adds a frame and
call/return burden without a benefit here; inline replacement cannot fit the
preserved combiner/fallback and violates the small entry footprint. Renderer
helper JSR and DO remain; “no entry JSR” is not “no stack use”.

`fQ = clamp(round(2^22 * f_reference * 2^(sign24(Y12F)/(65536*12)) / Fs), 1, 2^20)`
