# Focused original stock checkpoint provenance

recover.py reads existing original firmware, byte-verified narrow disassembly,
an authored cached patch member and existing extracted Components code. It runs
no application, ARM/DSP CPU, hardware or Plaits. Integer/static calculations trace
the original descriptor/getter/reverse-map and bank/word-offset chains; they are
not execution of an original stock invocation.

The selected raw file provides0/1/1 routing/nonlinear/filter fields. Original
table row1 gives5/5 ->intendedYF64..F68 with qualified arithmetic/AGU assumptions.
C2D supplies those dynamic words. Material numerical histories, modulation inputs,
modes and natural frames remain missing; numeric checkpoint admission is REFUSED.
Do not initialize those from boot/reset or turn the candidate into a runtime snapshot.

Reports:notes/stock-seam-checkpoint.md,stock-coefficient-provenance.md,
stock-runtime-state.md. Outputs:builds/phase20b-checkpoint/final/ and checks/.
verify.py requires byte-identical repeated fresh reports and original input guards.
No large installs, new RAM analysis, patch, repack or Plaits feeding.
