# Coefficient transfer and completion

**PROVEN:** original ARM `08035E28` initializes the four procedural families, then executes 16 resource-backed families with nine coefficient records each. `08035EC0` reads a 256-word descriptor count; `08035EC8` selects DSP X:$0C00. `08035ECE` enters16-bit SHI mode. `08035EE2→08047C6C` reads512 bytes into the global scratch pointer's observed ARM buffer `$20005148`. For the first record the NOR source is `$82000`.

`08035EEE→0802968E→0803BA96→080377DE` submits those512 bytes through SPI2 DMA1 stream4 TX, paired with stream3 RX. Observed TX CR `$10455` uses byte-width memory/peripheral accesses and incrementing source. SPI2 DR is `$4000380C`. Every modeled two-byte pair becomes one left-justified24-bit DSP word; the completed receiving extent is **X:$0C00,$0D00)**,256 words. This models source bytes in their actual order; it does not infer an authenticated source-file sample format from all-zero input.

**PROVEN:** the same ARM run delivers **144** such512-byte data DMAs plus144 two-byte restore commands. All data buffers are at `$20005148`, all modeled coefficient payload hashes equal SHA256 of512 zero bytes, and every data transfer advances from C00 to D00. [transfer-summary.json (local-only reference: `builds/phase65-shi-model-closure/transfer-summary.json`; not distributed) lists every DMA, source pointer, configuration and hash; shi-evidence.json (local-only reference: `builds/phase65-shi-model-closure/shi-evidence.json`; not distributed) retains the wire/model journal. native-dsp-job.txt (local-only reference: `builds/phase65-shi-model-closure/native-dsp-job.txt`; not distributed) records actual receiving X writes and unchanged native execution commands.

**PROVEN:** normal DMA completion is modeled only after all descriptor bytes are consumed. RX/TX stream EN and NDTR are cleared, transfer-complete state is raised, and actual native IRQ30 executes. Native `08023414–08023422` waits for its completion byte; the model does not return from that helper on its behalf. `08035EF4` restores24-bit SHI using command `20 00`; `08035F04` then posts the destination/selector0 job to Y:$2C. Before the next coefficient record, `08035EB2–08035EBE` reads the actual DSP mailbox until ARM receives `$80000000`, the left-aligned DSP `$800000` idle value. See candidate-08035e28.asm (local-only reference: `builds/phase65-shi-model-closure/candidate-08035e28.asm`; not distributed), candidate-080377de.asm (local-only reference: `builds/phase65-shi-model-closure/candidate-080377de.asm`; not distributed), candidate-08023414.asm (local-only reference: `builds/phase65-shi-model-closure/candidate-08023414.asm`; not distributed).
