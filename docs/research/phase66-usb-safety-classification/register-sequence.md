# Exact USB register and local sequence

**PROVEN:** `$40040008` is STM32F745 USB OTG HS `GAHBCFG`, the global AHB configuration register, at base `$40040000` plus8. Bit0 is the global interrupt enable, GINT; bit5 enables the controller's internal DMA. It is an ordinary readable/writable configuration register, not a FIFO or a read-to-pop status. Source: [ST device definitions](https://raw.githubusercontent.com/STMicroelectronics/cmsis-device-f7/master/Include/stm32f745xx.h), USB_OTG_HS_PERIPH_BASE, USB_OTG_GlobalTypeDef.GAHBCFG, GAHBCFG_GINT/DMAEN.

**PROVEN exact code:** `080381C8→08048316` loads GAHBCFG, shifts right1 then left1, stores it back at `0804831C`, returns0. It clears bit0 and preserves the other31 bits. No bit is tested for readiness and there is no loop. Normal progress requires only a responding peripheral register. The Phase65 unmapped-read exception was caused by the emulator's missing address range, not by firmware waiting for a USB event. `0804830E` performs the complementary bit0 enable.

**PROVEN next local conditions:** `080381DC→080481D4` configures the PHY interface and calls `08048A8E`. That reset helper waits for GRSTCTL bit31 AHBIDL, sets bit0 CSRST, and waits for it to clear. Its native countdown returns3 on timeout. `08038250→0804834A` initializes device registers and uses the self-clearing TX/RX FIFO flush bits5/4. These are the only finite hardware transitions added; no host reset, descriptor request, enumeration or packet-completion event was invented. Sources: candidate-0804830e.asm (local-only reference: `builds/phase66-usb-safety-classification/candidate-0804830e.asm`; not distributed), candidate-080481d4.asm (local-only reference: `builds/phase66-usb-safety-classification/candidate-080481d4.asm`; not distributed), candidate-08048a8e.asm (local-only reference: `builds/phase66-usb-safety-classification/candidate-08048a8e.asm`; not distributed), candidate-0804834a.asm (local-only reference: `builds/phase66-usb-safety-classification/candidate-0804834a.asm`; not distributed), candidate-080381a8.asm (local-only reference: `builds/phase66-usb-safety-classification/candidate-080381a8.asm`; not distributed).

**PROVEN bounded model:** [usb_model.py](<../../../builds/phase66-usb-safety-classification/usb_model.py>), `USBInit`, implements the observed device-initialization register latches, write-one-to-clear interrupt fields, idle-without-transfer status and delayed reset/flush completion. SR-style polling advances completion after three reads in the normal test profile; this is an abstract finite delay, not measured silicon latency. No pending bus events are supplied. Unknown registers, forced host mode, internal-DMA configuration and endpoint activation stop the model. There is no endpoint memory DMA or FIFO packet model.

**STRONG INFERENCE:** this minimal disconnected-device profile represents the successful conditions consumed by the observed startup. It is not a complete USB reset-value/peripheral implementation. Unused/reserved fields, endpoint traffic, bus speed/timing and physical host interoperability remain **UNKNOWN**. The current [ST low-level driver](https://raw.githubusercontent.com/STMicroelectronics/stm32f7xx-hal-driver/master/Src/stm32f7xx_ll_usb.c) supports these reset/flush semantics; it is not asserted to be the exact historical source/ABI of the candidate.

**PROVEN native sanity:** model-tests.json (local-only reference: `builds/phase66-usb-safety-classification/model-tests.json`; not distributed) has six checks: interrupt-bit clear without a wait, normal reset, delayed reset, AHB never idle, reset never completes, and rejection of unsupported endpoint activation. Actual `08048316/08048A8E` bytes execute in isolated argument fixtures. Both missing-condition cases take the real return3 path. Geometry canaries remain unchanged. These fixtures are never inserted into startup RAM.
