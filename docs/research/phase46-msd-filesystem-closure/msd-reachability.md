## Native data path and bounds

`200037AC → 20003788` is the backend table. Capacity callback `08057E34` always returns8192 blocks of4096 bytes, independent of the selected window. Read callback `08057E88` accepts block<8192; lower write callback `08057EF4` has the same block check. Geometry records at `08038C3C/44/4C` contain `{94000,D3FFF}`, `{0,1FFFFFF}`, `{D4000,1FFFFFF}`. The end fields do not bound the shown lower read/write arithmetic. Default mode1's maximum lower-callback start is`02093000`, and its4096-byte extent ends`02094000`, exceeding the nominal32MiB array. Physical alias behavior is **UNKNOWN**; no datasheet assumption is used to turn this into a demonstrated overwrite.

**PROVEN:** `0803B572` WRITE(10), state0, calls table+8 ready → `08057E44` (0), then table+C protection → `08057E48` (1). Nonzero protection branches to DATA PROTECT key7 / ASC27 before LBA arithmetic, data reception or write callback. Eighteen native cases cover both supplied LUN values0/1, target blocks81/82, boundary8191/8192, wrap inputs, zero count and65535 count; all rejected. Actual GET MAX LUN callback `08057FB0` returns0. The LUN1 tests are adversarial dispatcher inputs, not an advertised second medium.

After successful admission (not attainable through that protection predicate), SCSI would slice transfers into <=4096 bytes, i.e. one block per callback. It compares `LBA+16-bit count` to advertised block count using a32-bit unchecked addition at `0803B5EE`; malformed addition can wrap. Phase45's injected count>1 lower-callback overflow is not a normal admitted SCSI chunk. SCSI continuation at `0803B62E` skips initial protection; proving all BOT state/CBW lifetime invariants is distinct from proving the state0 branch.
