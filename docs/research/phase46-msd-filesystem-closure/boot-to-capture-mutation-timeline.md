# Phase46 — exact intended mutation window

This is a proposed input policy for analysis, not hardware action performed or permission to flash. One completed selector0 B1.3→corrected installation is the starting transition. No resource update, factory erase, identity edit, vendor mode-change, pack/project editing/save, unrelated Components session or unsolicited diagnostic command is included. Ordinary USB enumeration and normal host SCSI traffic, if the settings expose MSD, cannot simply be assumed absent. Startup restore and automatic settings work must be included regardless of user inactivity.
