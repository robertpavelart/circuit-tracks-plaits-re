**PROVEN:** resource helper47C6C maps r0/r1/r2 to wrapper arguments (offset/destination/length), BLX47C7E→24130 and POP47C80 preserves R0 status. First caller return instruction is08035EE6. It immediately replaces R0 with the staging-pointer literal, with no success check. At35EEE→2968E→3BA78 the512 bytes are sent to DSP0 X:C00..CFF with SHI in16-bit mode;35EF4 restores24-bit mode. The ARM branch does not apply an in-place evidence conversion. At35F08/35F0C it advances to another descriptor and repeats35EE2 with the **same staging buffer**; the next physical read can overwrite its beginning, and later table jobs reuse it. Source lifetime is therefore one read/upload iteration, not until USB enumeration. The earliest known next native read submission is35EE2 on the next iteration; the first actual overwrite is asynchronous DMA, with no single ARM STR instruction marking that instant. app-08047c6c.asm (local-only reference: `builds/phase54-early-evidence-snapshot/app-08047c6c.asm`; not distributed), app-08035e28.asm (local-only reference: `builds/phase54-early-evidence-snapshot/app-08035e28.asm`; not distributed), app-0802968e.asm (local-only reference: `builds/phase54-early-evidence-snapshot/app-0802968e.asm`; not distributed), app-0803ba78.asm (local-only reference: `builds/phase54-early-evidence-snapshot/app-0803ba78.asm`; not distributed).

**UNKNOWN:** a universal time duration or arbitrary-interrupt writer exclusion for this buffer. ## Native boundary checks

**PROVEN:** six fresh tests run unmodified instructions with synthetic backend outcomes0/1/2. Identity read arguments are exactly81000/20006868/23; byte14 is zeroed even after failure. Resource read arguments are82000/20005148/512; the unmodified caller reaches upload for all three statuses.
